# 机会合成方法论：从信号到"值得做的赛道"

本文件的唯一使命：把散落的 DemandSignal 合成为**可执行的赚钱机会卡片**。
每张卡片要回答四个问题：需求是否真实？流量从哪来？怎么变现？凭什么是我能做？

## 一、跨源共振：机会的成立条件

单一来源的信号只是线索，**至少 2 个独立来源指向同一方向**才构成机会候选：

| 共振组合 | 强度 | 含义 |
|---|---|---|
| 收入验证(revenue) + 痛点(complaint) | ★★★ | 别人赚着钱、用户还在骂——最理想：需求+付费意愿+改进空间三者齐备 |
| 新事物(new_product) + 趋势(trend) | ★★★ | 新模型/新游戏上线 + 搜索量正在起——抢时间窗 |
| 求助(request) + 趋势(trend) | ★★ | 有人在问 + 搜索在涨——长尾需求成型 |
| 新事物(new_product) 单独 | ★ | 只是线索：别人在做不等于有需求，需 trend/搜索验证 |
| 趋势(trend) 单独 | ★ | 搜索在涨但不知道为什么涨，需溯源 |

信号类型权重（用于在同一共振里排优先级）：
`revenue 1.5 > complaint 1.3 > request 1.2 > alternative 1.2 > new_product 1.0 > trend 0.8`

## 二、变现路径判断：广告流量站 vs 工具订阅

这是每张卡片必须给出的判断。判断依据是**信号里透露的搜索意图类型**：

### 走广告的信号特征（流量站打法）
- 联想词/趋势词是**信息型意图**："how to play X"、"X codes"、"best X games"、"X wiki/characters"
- 需求来自**玩家/读者**，一次性消费内容，不需要账号
- 证据样式：suggest 词根衍生出大量内容型长尾、Reddit 上求推荐帖多
- 形态：攻略站、合集站、codes 站、数据库站、Wiki 站
- 变现逻辑：SEO 获取搜索流量 → AdSense/广告联盟
- 风险：纯流量模式吃词根的搜索量，**必须在卡片里标注"待验证：Keyword Planner 查量"**

### 走订阅的信号特征（工具站打法）
- 信号里有**付费意愿的直接证据**：价格抱怨（"too expensive"）、替代品搜索（"X alternative"）、收入验证（同类产品 MRR）、功能缺口（"missing Y"）
- 需求来自**有任务要完成的用户/商家**，重复使用、愿意省时间
- 证据样式：complaint/alternative/revenue 类信号 + Toolify 收入榜同类产品存在
- 形态：单点工具、API 服务、浏览器插件、SaaS
- 风险：工具要维护、要有差异化；巨头赛道不进（卡片里标注竞争粗判）

### 混合（hybrid）
- 工具免费引流 + 进阶订阅；或攻略站引流 + 周边工具订阅。适合需求同时具备信息型与任务型意图时。

## 三、竞争粗判（不花额度的快速版）

卡片里必须写竞争现状与依据，允许粗判但禁止臆造：

1. **供给密度观察**（已有证据）：Toolify/Reddit 同类新品的上新频率——上新密集 = 赛道热但也拥挤；
2. **词的直观竞争**：联想词里是否已被大站词占据（"io games poki" 说明 poki 占位）；
3. **待验证项明确列出**：SERP 前三页强域名数、KD 值——留给下一步 Keyword Planner / Semrush 环节，卡片里写"待验证"，不冒充结论。

## 四、置信度评级

- **high**：≥3 来源共振 + 有付费意愿证据或收入验证 + 竞争有明确缝隙
- **medium**：2 来源共振，证据链完整但缺收入验证或竞争未明
- **low**：方向有趣但关键环节靠推断——一般不发卡片，除非特别值得盯

## 五、纪律

1. **每张卡片至少引用 2 个独立来源的具体信号**（实体+数字+链接），写进 evidence；
2. **推断必须标"待验证"**，下一步动作写具体（查什么词、看什么页）；
3. **无强机会就写"今日无强机会"**——宁缺毋滥，凑数的卡片会稀释注意力；
4. 机会卡片同样进 `opportunities` 数组入库，后续用真实流量/收入数据回填验证闭环（哪些判断对了、哪些错了），方法论据此迭代。
